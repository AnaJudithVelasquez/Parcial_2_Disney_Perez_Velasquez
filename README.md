# 🌐 Final Project: Disney Webpage Layout

This project is a recreation of the Disney website using only **HTML** and **CSS**, with a strong focus on staying true to the original design provided.

### 🛠 Tools Used
* **HTML:** To create the structure and the actual content of the page.
* **CSS:** To apply colors, fonts, effects, and ensure every element matches the reference design.
* **Git & GitHub:** For version control, saving progress, and working as a team.

### 🎯 What was achieved?
The main goal was to maintain visual precision in every part of the site:

* **Navigation Bar:** Top menu featuring the Disney logo, a styled search bar, and navigation links.
* **Main Banner (Hero):** The forest background with the "Snow White" title layered on top, keeping the exact alignment from the design.
* **Content Sections:**
    * **Shop:** A purple area with detailed yellow cards.
    * **Disney+:** A dark blue space to highlight movies from the platform.
    * **Parks & Cinema:** A dedicated section for Disney Parks and upcoming movie releases.
* **Footer:** We included the bottom menu, social media icons, and legal text, following the professional structure of the real site.

### 🧠 The Biggest Challenge
The main challenge was making sure the "Snow White" logo stayed in its perfect position over the forest image without breaking or moving weirdly when resizing the window. We also paid close attention to colors and spacing (paddings/margins) to ensure they were identical to the assigned design. Additionally, we improved our **Git** skills for collaborative work.
